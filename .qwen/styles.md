# Стили и SCSS

## Главное правило
Везде используем **CSS Modules** с расширением `.module.scss`

**Пример:**
```scss
// component.module.scss
.container {
  padding: var(--spacing-md);
}
```

```tsx
// component.tsx
import styles from './component.module.scss'

<div className={styles.container} />
```

---

## 1. Структура файлов

Миксины группируются по функциональному назначению в `shared/styles/mixins`.

- Имя файла отражает тему: `_scrollbar.scss`, `_animations.scss`, `_fluid.scss`
- Каждый файл начинается с комментария-описания

---

## 2. Документирование миксинов

Каждый миксин сопровождается комментарием в стиле JSDoc:

- Краткое описание
- Детальное описание
- @param для каждого параметра
- @example минимум два примера

---

## 3. Именование миксинов

- kebab-case: `custom-scrollbar`, `fade-in-up`
- Уникальные и понятные имена

---

## 4. Параметры миксинов

- Значения по умолчанию для всех параметров
- CSS переменные для цветов
- Единицы измерения в документации

---

## 5. Содержание миксина

- Чистый код с комментариями
- @supports для кросс-браузерности
- Уникальные keyframes для анимаций

---

## 6. Примеры использования

- Минимум 2 примера в документации
- Реалистичные имена классов

---

## 7. Проверка наличия миксинов

- Проверять `shared/styles/mixins` перед созданием
- Локально только для одного компонента

---

## 8. Рефакторинг

- Обновлять документацию при изменении
- Не ломать обратную совместимость
- Помечать @deprecated

---

## 9. Именование классов

- kebab-case: `.user-card`, `.nav-item`
- Вложенность не более 3 уровней
- Без ID селекторов

---

## 10. CSS переменные

- Все темизируемые значения через `var()`
- Переменные в `shared/styles/variables.css`

---

## 11. Адаптивность

- Mobile-first подход
- Брейкпоинты в переменных
- fluid-property для типографики

---

## 12. Примеры миксинов

- `custom-scrollbar` (`_scrollbar.scss`)
- `fade-in-up` (`_animations.scss`)
- `fluid-property` (`_fluid.scss`)
