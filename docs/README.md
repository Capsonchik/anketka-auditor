# Документация проекта

Добро пожаловать в документацию **BI Next App** — Next.js приложения с FSD архитектурой.

## Быстрый старт

### Установка зависимостей

```bash
cd docs
npm install
```

### Запуск разработки

```bash
npm start
```

Откроется браузер на `http://localhost:3000` с горячей перезагрузкой.

### Сборка

```bash
npm run build
```

Создаст статический сайт в папке `build/`.

### Локальный сервер

```bash
npm run serve
```

Запустит локальный сервер для просмотра собранной версии.

## Автоматическая генерация

Документация генерируется автоматически из:

1. **Исходного кода** — TypeScript типы, JSDoc комментарии
2. **Файлов `.qwen/`** — правила, инструкции, архитектура
3. **SCSS файлов** — переменные, миксины

### Обновление документации

При изменении файлов в `.qwen/` или исходном коде:

```bash
# Копирование правил в документацию
npm run sync:docs
```
