# SUMMARY — Survey-all: Кабинет Аудитора (auditor_frontend)

## Описание проекта

`auditor_frontend` — фронтенд-модуль личного кабинета аудитора для платформы **Survey-all**.
Аудитор через кабинет управляет своими проверками торговых точек (KVI-мониторинг, полочный
мониторинг, чек-лист аудит): видит метрики, список заданий, карту, статистику эффективности,
инструкции и форму поддержки.

Модуль реализован по методологии **Feature-Sliced Design (FSD)** и предназначен для
интеграции в **Next.js (App Router)** приложение-хост. Сам по себе он не является отдельным
запускаемым приложением — это набор переиспользуемых страниц, виджетов, фич и UI-компонентов,
экспортируемых через корневой `index.ts`.

## Технологический стек

| Категория | Технологии |
|---|---|
| Язык | TypeScript + React (`.tsx`) |
| Фреймворк | Next.js (App Router, `next/navigation`) |
| Стилизация | SCSS Modules + CSS-переменные |
| Архитектура | Feature-Sliced Design (слои: `core/entities/features/widgets/pages/shared`) |
| State | Локальный `useState` (без Redux/Zustand) |
| Данные | Моковые данные (`mock.ts`) — реального API-слоя пока нет |
| Утилиты | Собственная `cn()` вместо `clsx` |

## Ключевые возможности

1. **Дашборд** — приветствие, метрики (рейтинг, балл, баланс), карточки статистики, ближайшие задачи, уведомления.
2. **Мои задания** — фильтруемый список карточек заданий с действиями (начать, продолжить, скачать оффлайн, подать заявку).
3. **Карта заданий** — имитация карты с цветными маркерами по статусам + легенда.
4. **Эффективность** — рейтинг, баланс, недельная статистика, история выполненных заданий (таблица).
5. **Профиль** — данные аудитора, рейтинг, баланс, быстрые ссылки на инструкции/поддержку.
6. **Инструкции** — статичные карточки правил (фотофиксация, чек-лист, легенда, ценофиксация).
7. **Поддержка** — форма обратной связи с экраном успешной отправки + контакты.
8. **Оффлайн-режим** — переключатель онлайн/оффлайн в шапке (тоггл).
9. **Обработка ошибок** — `ErrorBoundaryProvider` оборачивает практически каждый компонент; стандартный `ErrorFallback` с модалкой деталей ошибки.
10. **UI-кит** — кастомный `Button` (15 анимаций, 6 вариантов, 3 appearance), `Picker` (Select/Check), `Modal` (portal, backdrop), `PageContainer`, `ErrorFallback`.

## Статус проекта

- **Стадия**: прототип/UI-макет, перенесённый из статичного `demo.html` в React-компоненты.
- **Данные**: только моки (`entities/*/model/mock.ts`). API-слой, аутентификация, персистентность оффлайн-режима отсутствуют.
- **Навигация**: реализована через `next/navigation` (`useRouter`/`usePathname`), маршруты вида `/auditor/*`.
- **Тесты**: отсутствуют.
- **Конфигурация сборки**: в данном модуле нет (`package.json`, `tsconfig.json`, `next.config` находятся на уровне хост-приложения).

## Структура слоёв (FSD)

- **core/** — провайдеры инфраструктуры (ErrorBoundary).
- **entities/** — бизнес-сущности `task` и `user` (типы + моки + функции-селекторы).
- **features/** — композиционные блоки: `dashboard-stat-card`, `task-card`, `task-filters`, `welcome-metrics`.
- **widgets/** — крупные блоки: `auditor-header` (шапка), `auditor-nav` (нижняя навигация).
- **pages/** — 7 страниц: `dashboard`, `tasks`, `map`, `stats`, `profile`, `instructions`, `support`.
- **shared/** — переиспользуемое: `lib/cn`, `hooks`, `ui` (Button, Picker, Modal, PageContainer, ErrorFallback), `styles` (SCSS-переменные/миксины).
- **index.ts** — баррель-экспорт модуля (entities, features, widgets, shared; pages экспортируются отдельно).

## Зависимости от хост-приложения

- Алиас импортов: `@/auditor_frontend/...` (настроен в `tsconfig` хоста).
- Next.js: `next/navigation` (`useRouter`, `usePathname`).
- React 18+ (хуки, классовые компоненты для ErrorBoundary, `createPortal`).
