# Logo

Компонент **Logo** — официальный логотип компании «РОМИР» с поддержкой смены тем и гибкой настройкой размеров.

## Пример использования

```tsx
import { Logo } from '@shared/ui';

const Header = () => {
  return (
    <Logo 
      width={160} 
      height={44} 
      to="/dashboard"
    />
  );
};
```

## Свойства (Props)

| Свойство | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `width` | `number` | `588` | Ширина логотипа в пикселях |
| `height` | `number` | `159` | Высота логотипа в пикселях |
| `to` | `string` | `'/'` | Путь для навигации при клике (использует `next/link`) |
| `className` | `string` | — | Дополнительный CSS-класс |

## Особенности реализации

- **Поддержка тем**: Логотип автоматически меняет свой цвет в зависимости от текущей темы приложения (черный для `light`, белый для `dark`). Это реализовано через хук `useTheme` внутри компонента [LogoIcon](file:///c:/romir-frontend/bi/next-app-pattern/src/shared/icons/logo-icon/logo-icon.tsx).
- **Встроенная навигация**: По умолчанию логотип является ссылкой на главную страницу приложения.
- **Векторная графика**: Использует SVG для обеспечения четкости при любых размерах.
