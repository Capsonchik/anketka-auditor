# Стилизация

В проекте используется **SCSS** с **CSS Modules** для обеспечения изоляции стилей компонентов.

## Цветовая палитра

Система цветов построена на основе числовой шкалы (100-900), где `500` — базовый оттенок.

- **`--color-primary-500`**: Основной цвет бренда.
- **`--color-gray-900`**: Основной цвет текста.
- **`--color-gray-100`**: Второстепенный цвет фона.

Все цвета генерируются в файлах `src/shared/styles/themes` и доступны в виде CSS-переменных.

### Пример использования

```scss
.my-component {
  // Используем CSS-переменные
  background-color: var(--color-primary-100);
  color: var(--color-primary-700);
  border: 1px solid var(--color-gray-300);
}
```

В SCSS-файлах также доступны SCSS-переменные из `_theme-tokens.scss` для удобства:

```scss
.my-component {
  // Используем SCSS-переменные
  background-color: $color-primary-100;
  color: $color-primary-700;
  border: 1px solid $color-gray-300;
}
```

## Размеры и отступы

Для отступов и размеров используются предопределенные переменные из `_sizes.scss`.

- `$spacing-1` (4px)
- `$spacing-2` (8px)
- `$spacing-3` (12px)
- ...

## Миксины

В проекте есть набор полезных миксинов в `src/shared/styles/mixins`:

- `custom-scrollbar`: Стилизация скроллбара.
- `fade-in-up`: Анимация появления.
- `fade-out`: Анимация исчезновения.

## Автоматический импорт

Все SCSS-переменные и миксины автоматически импортируются в каждый `.module.scss` файл благодаря настройкам в `next.config.ts`. Вам не нужно импортировать их вручную.
