# Архитектура

Проект построен на основе методологии **Feature-Sliced Design (FSD)**, адаптированной для **Next.js App Router**.

## Основные слои

Структура проекта строго разделена на слои, которые могут взаимодействовать друг с другом только в направлении "сверху вниз".

```
src/
├── app/         # Глобальные настройки, стили и провайдеры
├── pages/       # Страницы приложения (если используются)
├── widgets/     # Крупные, самодостаточные блоки (Header, Sidebar)
├── features/    # Пользовательские сценарии (авторизация, поиск)
├── entities/    # Бизнес-сущности (User, Product, Order)
└── shared/      # Переиспользуемый код (UI-кит, утилиты, API)
```

### Правила импорта

| Слой | Может импортировать |
|---|---|
| `app` | `pages`, `widgets`, `features`, `entities`, `shared` |
| `pages` | `widgets`, `features`, `entities`, `shared` |
| `widgets` | `features`, `entities`, `shared` |
| `features` | `entities`, `shared` |
| `entities` | `shared` |
| `shared` | Только другие модули `shared` и внешние библиотеки |

> ❌ **Запрещено:** Импортировать код из слоев, находящихся выше. Например, `entities` не может импортировать `features`.

## Сегменты внутри слоев

Каждый модуль (слайс) внутри слоя может быть разделен на сегменты для лучшей организации:

- **ui:** React-компоненты и их стили.
- **model:** Логика управления состоянием (Redux, Zustand, React Query).
- **api:** Функции для взаимодействия с API.
- **lib:** Вспомогательные утилиты и хуки.
- **types:** Определения TypeScript-типов.

## Публичное API (`index.ts`)

Каждый слайс должен иметь файл `index.ts`, который экспортирует только то, что можно использовать другим модулям. Это обеспечивает инкапсуляцию и контроль над зависимостями.

**Пример:**

```typescript
// entities/user/index.ts
export { UserCard } from './ui/UserCard';
export { useUserStore } from './model/useUserStore';
export type { User } from './types';
```

## Проверка зависимостей

Для автоматического контроля за соблюдением правил импорта используется ESLint с плагином **@feature-sliced/eslint-config**.
