# Button

Компонент **Button** — это универсальная кнопка с поддержкой множества размеров, цветов, стилей отображения и 14 видов анимации при наведении.

## Пример использования

```tsx
import { Button } from '@shared/ui';

const MyComponent = () => {
  return (
    <Button 
      variant="primary" 
      size="md" 
      animation="ripple"
      onClick={() => console.log('Клик!')}
    >
      Нажми меня
    </Button>
  );
};
```

## Свойства (Props)

| Свойство | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Размер кнопки |
| `variant` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info'` | `'default'` | Цветовая схема |
| `appearance` | `'default' \| 'subtile' \| 'ghost'` | `'default'` | Стиль отображения (заливка, текст или контур) |
| `animation` | `ButtonAnimation` | `'none'` | Анимация при наведении (см. список ниже) |
| `leftIcon` | `ReactNode` | — | Иконка слева от текста |
| `rightIcon` | `ReactNode` | — | Иконка справа от текста |
| `loading` | `boolean` | `false` | Состояние загрузки (показывает лоадер) |
| `active` | `boolean` | `false` | Принудительное активное состояние |
| `block` | `boolean` | `false` | Растягивание на всю ширину контейнера |

## Анимации (`animation`)

Компонент поддерживает 14 типов анимации:

1. `swipe` — сдвиг фона слева направо.
2. `diagonal-swipe` — диагональный сдвиг фона.
3. `double-swipe` — сдвиг фона с двух сторон к центру.
4. `diagonal-close` — смыкание диагональных полос.
5. `zoning-in` — появление фона из четырех сторон к центру.
6. `four-corners` — появление фона из углов к центру.
7. `slice` — эффект "разрезания" (треугольники сверху и снизу).
8. `position-aware` — фон следует за курсором мыши.
9. `alternate` — чередующиеся полосы фона.
10. `smoosh` — вертикальное смыкание фона.
11. `vertical-overlap` — плавное вертикальное перекрытие слоями.
12. `horizontal-overlap` — плавное горизонтальное перекрытие слоями.
13. `collision` — столкновение двух кругов, переходящее в фон.
14. `ripple` — круговая волна, растущая из центра.

## Особенности реализации

- **Динамические размеры**: Кнопка использует `ResizeObserver` для передачи своих размеров в CSS-переменные `--btn-width` и `--btn-height`, что необходимо для работы сложных анимаций.
- **Темы**: Кнопка автоматически адаптирует свои цвета под светлую и темную темы приложения.
- **Синхронизация с Primary Color**: Вариант `primary` использует глобальную переменную `--primary-500`, которую пользователь может менять через `ColorPicker`.
