# Survey-all — Кабинет аудитора

Веб-приложение кабинета аудитора платформы **Survey-all**:  
[https://auditor.survey-all.ru/](https://auditor.survey-all.ru/)

Аудиторы и контролёры работают с проверками торговых точек (мониторинг цен, чек-листы и связанные задания): смотрят список назначений, открывают проверку, заполняют анкету, отправляют результаты. На карте видны свои и свободные проверки, можно подать заявку. Есть профиль, статистика, инструкции и поддержка.

---

## Роли

| Роль | Что делает |
| :--- | :--- |
| **Аудитор** | Получает задания, принимает/отклоняет назначения, проходит анкету, сохраняет черновик и отправляет ответы, работает с картой и заявками на свободные проверки |
| **Контролёр** | Контролирует качество выполненных проверок, запрашивает доработки по вопросам (в кабинете аудитора отображаются треды доработки) |

Типичный поток аудитора: **Мои задания** → открыть проверку → заполнить форму → отправить → при необходимости ответить на доработку. Параллельно — **Карта** для геопривязанных точек.

## Быстрый старт

```bash
npm install
npm run all
```

| Сервис | URL | Порт |
| :--- | :--- | :--- |
| **Приложение (Dev)** | [http://localhost:3002](http://localhost:3002) | `3002` |
| **Storybook** | [http://localhost:6006](http://localhost:6006) | `6006` |
| **Документация** | [http://localhost:4002](http://localhost:4002) | `4002` |

Отдельно:

```bash
npm run dev        # только приложение
npm run storybook  # UI-песочница
npm run docs       # Docusaurus
npm run lint       # проверка кода
```

## Архитектура (FSD)

Проект следует **Feature-Sliced Design**:

- `app/` — App Router, провайдеры, layout кабинета
- `widgets/` — шапка, нижняя навигация и крупные блоки
- `features/` — формы входа/профиля, заполнение проверки, карта и др.
- `entities/` — assignment, auditor, map-marker, public-pa, stats
- `shared/` — UI-kit, API (RTK Query + proxy), стили, утилиты

---

## Основные разделы кабинета

- **Главная** — обзор и метрики
- **Мои задания** — список назначений, переход к конкретной проверке
- **Карта** — маркеры проверок, фильтры, заявки на свободные
- **Профиль / статистика** — данные аудитора и эффективность
- **Инструкции / поддержка** — справка и обратная связь

Заполнение анкеты идёт через публичный PA-пайплайн бэкенда (`inviteToken` + `checkId`), без дублирования submit-логики на фронте.

## i18n

На базе **i18next**:

1. В коде: `useTranslation` + `t('…')`
2. `npm run i18n:extract` — ключи в `messages/ru.json`
3. `npm run i18n:translate` — автоперевод в `messages/en.json`
