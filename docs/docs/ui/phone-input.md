# PhoneInput

Компонент **PhoneInput** — специализированное поле ввода номера телефона с поддержкой масок стран СНГ и автоматическим определением страны.

## Пример использования

```tsx
import { PhoneInput } from '@shared/ui';

const MyComponent = () => {
  const [phone, setPhone] = useState('+79998887766');

  return (
    <PhoneInput 
      value={phone} 
      onChange={setPhone} 
      label="Номер телефона" 
    />
  );
};
```

## Свойства (Props)

Компонент наследует все свойства [Input](/docs/ui/input), за исключением `onChange` и `value`.

| Свойство | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `value` | `string` | — | Номер в формате `+79998887766` |
| `onChange` | `(value: string) => void` | — | Возвращает очищенное значение с префиксом `+` |
| `allowedCountries` | `string[]` | — | Массив кодов разрешенных стран (например, `['RU', 'BY']`) |
| `hideFlag` | `boolean` | `false` | Скрывает селектор флага |

## Особенности реализации

- **Маски ввода**: Поддерживает специфические маски для России (+7), Беларуси (+375), Казахстана (+7), Узбекистана (+998) и других стран СНГ.
- **Автоопределение**: При вводе префикса страны (например, `+375`), компонент автоматически переключает флаг и применяет нужную маску.
- **Селектор стран**: Включает в себя выпадающий список для ручного выбора страны.
- **Валидация**: Очищает ввод от любых символов, кроме цифр и начального знака `+`.
