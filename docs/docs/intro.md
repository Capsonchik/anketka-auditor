# Введение

Добро пожаловать в документацию проекта **BI Next App Pattern**.

Это проект на [Next.js](https://nextjs.org) с FSD-архитектурой и собственной UI-библиотекой в стиле React Suite.

## 🚀 Быстрый старт

### Запуск приложения

```bash
npm run dev
```

После запуска приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

### Запуск Storybook

Для просмотра и разработки компонентов UI-библиотеки используйте Storybook.

```bash
npm run storybook
```

Storybook будет доступен по адресу [http://localhost:6006](http://localhost:6006).

## 🛠 Технологии

- **Next.js 16** — React фреймворк
- **TypeScript** — типизация
- **Redux Toolkit** — управление состоянием
- **Storybook** — разработка и документирование UI-компонентов
- **Docusaurus** — документация проекта
- **SCSS (CSS Modules)** — изолированные стили компонентов
